EASY IMAGE SWAPS

This folder is for website artwork that should be easy to replace without editing index.html.

Current featured image:
- afterlife_io_feature.jpg

To swap it:
1. Open assets/images/easy_swap in GitHub.
2. Replace afterlife_io_feature.jpg with your new JPG using the exact same filename.
3. Commit the replacement.
4. Hard-refresh the website if your browser cached the previous image.

Recommended image shape: wide 16:9-ish artwork. Keep files reasonably compressed for quick page loading.

The old afterlife_io text chunks are no longer used by the page and can be treated as legacy data.
