# GLITCHED MATRIX Prototype Lab

Public website and browser experiments for **GLITCHED MATRIX Prototype Lab / Matrix OS: Arcade Evolution**.

The Prototype Lab is a playable operating-system arcade that connects evolving games, creative tools, MatrixCore music, Utopia archives, simulations, bots, and experimental worlds.

## Public site

The repository contains the static public website used to present the project and link visitors to the Steam release.

The current site includes:

- A refreshed MXOS and Prototype Lab overview
- A selected-project showcase
- The preserved HoloMap RTS browser experiment
- MatrixCore and Utopia lore readers
- Prototype screenshots and media
- Steam, trailer, and community links

## Development approach

Public changes should be made conservatively:

1. Preserve the working browser experiment and lore reader.
2. Add new presentation work through clearly named files.
3. Test at 1920×1080 and 1280×720.
4. Avoid broken media paths and hidden internal-development copy.
5. Keep the Steam page as the primary release destination.
6. Use branches and pull requests for major public refreshes.

## Current refresh
